\chapter{模块概述}

\section{简介}

basicexam 是一个面向 \ConTeXt\ \LMTX\ 的试卷模块。它在 \ConTeXt\ 原生的
\type{itemgroup}之上增加了：题目层级的自动管理、答案与分数的统一收集、
教师/学生模式的切换。因此，用惯了 \ConTeXt\ 列表环境的用户可以直接上手，
而需要出卷、配答案、统计分数的用户则不必自己拼装计数器与答案表。

模块的目标用户是命题者与排版者：一份试卷的题干、选项、答案、解析、分值、
答题区域、成绩表，都可以在同一个源文件中完成，并通过模块参数或模式开关
输出教师版或学生版。

\section{核心设计}

理解 basicexam 只需要：

\startpoints
\item {\bf question 骨架}：几乎所有题目都是通过 \type{question} 环境进行拓展，
      \type{problem}、\type{choice}、\allowbreak\type{close}、\type{writing} 等环境
      都是它的特例或组合。题目可以进行近乎无限层级嵌套，层级关系由模块自动维护。
      对应本手册的题目环境章节：第 5--12 章。
\item {\bf 答案树}：每道题在编译时都会在答案树中注册一个节点，记录题号、分值、
      答案、子题关系。答案的显示、分数的统计、成绩表的生成，都从这棵树读取，
      无须手工维护计数器。对应本手册的答案与分数章节：第 6、8、9 章
\item {\bf 模式切换}：教师模式、学生模式、检查模式控制答案与分数的可见性。
      模式可以在模块加载时全局设定，也可以在题目中通过\type{showanswer} / 
      \type{showpoint} 单独设置。对应本手册的加载与模式章节：第 2--3 章
\stoppoints

\section{主要特性}

\subsection{题目组织}

\startpoints
\item 无限层级嵌套的 \type{question} 环境，以及用于子问题的 \type{problem}
\item 选择题 \type{choice}（含内联选择题 \type{inlinechoice}）
\item 填空题 \type{fillin}，支持下划线、编号、答案三种显示方式
\item 判断题 \type{truefalse}，正确答案与错误答案使用不同符号
\item 完形填空 \type{close}，选项随文放置，自动收集
\item 选项式填空 \type{optclose}
\item 写作题 \type{writing} / \type{subwriting}，配套作文格与方格纸
\item 材料阅读 \type{material}，配合 \type{\indicator} 建立材料与题目的关联
\stoppoints

\subsection{答案与分数}

\startpoints
\item 教师 / 学生 / 检查三种模式，控制答案、分数、答题区域的显示
\item 题目级 \type{showanswer}、\type{showpoint}、\type{showscript} 覆盖全局设置
\item 答案树自动收集答案与分值，支持无限层级子题的汇总
\item \type{\partio} / \type{\typegrade} 成绩表收集与输出
\item \type{\score} 在解析中标注得分点，配合 \type{\resetscore} 累计
\item 答案数据持久化到 \type{<jobname>-examdata.lua}，二次编译可读取
\stoppoints

\subsection{排版与样式}

\startpoints
\item 试卷标题 \type{\definepapertitle} / \type{\makepapertitle}，
      支持密级、主标题、科目、考试信息、签名区、注意事项等元素
\item 双页排版 \type{layout=twoup}，适合 A3 对折输出
\item 诗词排版 \type{verse}，按样本文本自动计算缩进
\item 词典条目 \type{lexicalentry}，支持词性、重音、释义、例句、反义词等
\item 选择、填空、答案、分数可通过对应的设置命令单独定制样式与颜色：
      \type{\setupchoice}、\allowbreak\type{\setupfillin}、\type{\setupsolution}、
      \type{\setupquestion}  
\stoppoints

\subsection{扩展与实验}

\startpoints
\item \type{\ORDER} 选项乱序与自动编号（实验性）
\item 内置符号与徽章，全部由 MetaFun 绘制，不依赖外部符号字体
\item 答案树 API：\type{\UnlimitedDisplayAnswer}、\type{\UnlimitedTotalPoint}
      等，可在文档中直接查询题目信息
\item check 模式下的调试输出与 \type{\UnlimitedExport} 导出
\stoppoints

\section{系统要求}

该模块需要 {\bf ConTeXt LMTX (LuaMetaTeX)} 环境，不支持 MkIV 版本。
如果在不兼容的环境下运行，模块会提示错误并终止编译。
标记符号与徽章使用 MetaFun 绘制，不需要安装额外的符号字体。

\chapter{试卷标题}

\section{papertitle 命令}

试卷标题是试卷的重要组成部分，通常包含考试名称、科目、年级、考试时间等信息。

\startbuffer

  title={2024 年普通高等学校招生全国统一考试},
  subject={数学},
  information={总分:150 分，考试时间:120 分钟}]
\makepapertitle[myexam]
\stopbuffer

\stopframedtext

\subsection{随机排序}

    \startcitem    选项四 \stopcitem

\question[showanswer=true]{这是选择题的题干内容。

\section{成绩收集与输出}

\type{\partio[uid]} 开启一个成绩收集分区；之后可用
\type{\typegrade[partios=uid,...]} 输出成绩表。
\type{partios} 留空时使用最新的 partio，也可以填数字、列表或
\type{all}。\type{\startpartio} / \type{\stoppartio} 可临时开启或

\starttyping

\startquestion[point=4,answer=B]
  下列哪一项是正确的？
  \choice{选项A,{[*]选项B},选项C,选项D}
\stopquestion

\typegrade[partios=first, layout=cols,

\stoptyping

\section{选项乱序}

\type{\ORDER} 按给定种子打乱一组条目，并自动编号。
用 \type{\setupORDER[...]} 修改全局默认值。

\starttyping
\ORDER[seed=42, numbering=characters]{甲,乙,丙,丁,戊}
\stoptyping

常用参数：\type{seed}（随机种子）、\type{symbol}（是否显示编号）、
\type{numbering}（\type{numbers}、\type{characters} 等）、
\type{distance}、\type{numberleft}、\type{numberright}、
\type{answermode}（\type{correct} 或 \type{shuffled}）。
乱序后的答案可用以下命令输出：

\starttyping
\ctxlua{thirddata.basicexam.collectd_orderanswer()}
\stoptyping

\section{Structure 层级统计}

\NC \type{\UnlimitedStructureLeafNumber{level}{number}} \NC 指定层级的顶层叶子节点数（独立大题数） \NC\NR

\HL
\stoptabulate

\subsection{参数说明}

\startpoints[packed]
\item \type{level}: 层级编号，1=chapter, 2=section, 3=subsection...
\item \type{number}: 该层级的编号（如第1章、第2章）
\stoppoints

{\bf 重要提示}：使用 \type{\UnlimitedCurrentStructure*} 命令时，必须在对应的章节/节结构内调用，否则会返回 0。

\subsection{统计概念说明}

\startpoints[packed]
\item {\bf 顶层题目（Major questions）}: 直接位于章节下的大题，不包含在其他题目内
\item {\bf 顶层叶子节点（Independent major questions）}: 没有子题的顶层大题，即独立大题
\item {\bf 所有叶子节点（All sub-questions）}: 所有实际需要作答的小题，包括嵌套的子题
\stoppoints

\subsection{统计示例}

假设第一章有以下题目结构：

\startbuffer
第一章
├── 大题1（有子题）
│   ├── 小题1.1
│   └── 小题1.2
├── 大题2（独立大题）
└── 大题3（有子题）
    ├── 小题3.1
    ├── 小题3.2
    └── 小题3.3
\stopbuffer

\typebuffer

统计结果：
\startpoints[packed]
\item 顶层题目数：3（大题1、大题2、大题3）
\item 顶层叶子节点数：1（只有大题2是独立大题）
\item 所有叶子节点数：6（小题1.1、1.2、大题2、小题3.1、3.2、3.3）
\stoppoints
